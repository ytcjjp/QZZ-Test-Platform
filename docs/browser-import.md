# 飞书浏览器导入

飞书文档由 **运行 QZZ 服务的电脑上的 Chrome** 读取。其他成员可以通过内网平台发起导入，无需在各自电脑安装扩展。读取使用服务器 Chrome 中已登录的飞书账号及其实际文档权限，不需要填写飞书 App ID 或 App Secret。

## 管理员首次连接

1. 在平台“需求管理”或“AI 用例生成”中打开“飞书浏览器连接”。知识库上传文档时也可从来源区域打开。
2. 点击“下载 Chrome 扩展”，解压 `QZZ-Feishu-Browser.zip`，保留其中的 `browser-extension` 文件夹。
3. 在服务器电脑的 Chrome 地址栏输入 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择含 `manifest.json` 的 `browser-extension` 文件夹。扩展需 Chrome 120 或更新版本。
4. 在同一个 Chrome 中登录飞书，先确认该账号能打开目标文档，且有阅读、复制内容所需权限。
5. 回到平台连接窗口，点击“生成一次性配对码”。再打开 Chrome 工具栏的“QZZ 飞书文档导入”，填写平台端口（默认 `3210`，以实际配置为准）和平台显示的 12 位配对码，点击“配对并连接”。
6. 平台显示“服务器 Chrome 已连接”后，粘贴飞书文档地址导入。浏览器连接状态只说明扩展与服务器连通，不代表文档已经授权或读取成功。

配对码仅可使用一次，5 分钟后过期。重新生成配对码会使旧码失效、断开旧浏览器连接，并取消进行中的导入。下载、配对和从平台断开连接只对平台管理员开放；普通成员可查看状态。

## 日常导入

在需求管理、知识库的来源输入区域或 AI 文档导入区粘贴飞书地址。支持 HTTPS 的飞书 / Lark `docx`、`docs`、`wiki` 文档链接。平台会显示服务器浏览器状态，导入过程中扩展打开自己的后台标签页，读取结束后将其关闭，不切换用户当前标签页。

服务器电脑和该 Chrome 必须保持运行。Chrome 已配对但离线时，先启动相应 Chrome；扩展会尝试连接本机平台。修改平台端口、更换 Chrome 配置文件或换服务器后，需要重新配对。普通成员电脑上的飞书登录状态不会传到服务器；链接必须允许服务器 Chrome 中的账号读取。

账号过期、未登录、权限不足、文档限制复制或页面无法完整加载时，先在服务器 Chrome 处理后重新导入，也可以从飞书导出 Word / PDF 再上传。扩展不绕过文档访问或复制限制。

## 完整性与图片

扩展读取页面实际加载的正文、标题、列表、表格和图片。正文通常最多约 2 分钟，单次导入任务最多约 3 分钟；具体错误会在平台显示。包含折叠内容、不支持的嵌入对象、画板或图表、未完整加载的文本或图片时，系统会提示“部分读取”及缺失项。出现此类提示时应补充原件或截图，不能把部分结果当作完整文档。

当前导入范围为每份正文最多 10 万字、图片最多 64 张、合计最多 64 MiB，单图最多 4000 万像素。超出限制需拆分或补充原件；动图只读取首帧。平台只接收文档内容、实际读取到的图片和完整性说明，不接收 Chrome Cookie 或其他标签页内容。

## 状态排查

| 平台状态或错误 | 处理方式 |
| --- | --- |
| 服务器 Chrome 未连接 | 管理员先安装扩展并生成配对码完成连接。 |
| 已配对，当前离线 | 启动已配对的服务器 Chrome，检查扩展是否启用，在扩展中点击“重新连接”。 |
| 连接状态暂不可用 | 检查 QZZ 服务与内网连接，点击“刷新状态”；登录失效时重新登录平台。 |
| 已连接，但文档无法导入 | 用服务器 Chrome 直接打开该链接，确认飞书登录、文档阅读与复制权限。 |
| 配对码过期或无效 | 重新生成配对码，使用最新配对码在有效期内连接。 |
| 图片缺失或提示部分读取 | 补充原始 Word / PDF、图片或截图后重新确认用例覆盖范围。 |

## 验证边界

自动化接口和浏览器界面检查不代表真实企业飞书页面已验收。正式使用前，需在服务器 Chrome 中安装扩展，并选取有权限的文字、表格、图片和长文档分别导入，核对原件与导入结果。扩展权限、打包和开发测试详见 [扩展说明](../browser-extension/README.md)。
